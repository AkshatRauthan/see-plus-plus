## Compilation Pipeline

The compilation process was performed manually using GCC:

```bash
clang -E hello.c -o build/hello.i           # Preprocessing
clang -S build/hello.i -o build/hello.s     # Compilation
clang -c build/hello.s -o build/hello.o     # Assembly
clang build/hello.o -o build/hello          # Linking
```

| Stage         | Output    | Description                                                              |
| ------------- | --------- | ------------------------------------------------------------------------ |
| Preprocessing | `hello.i` | Expands macros, includes headers, and processes preprocessor directives. |
| Compilation   | `hello.s` | Translates preprocessed C code into assembly.                            |
| Assembly      | `hello.o` | Converts assembly into machine code (object file).                       |
| Linking       | `hello`   | Links the object file with required libraries to produce an executable.  |

## Optimization Comparison

Generated assembly using two optimization levels:

```bash
clang -O0 -S hello.c -o build/hello_O0.s
clang -O2 -S hello.c -o build/hello_O2.s
```

- `-O0`: Disables compiler optimization.
- `-O2`: Enables a broader set of performance optimizations.

Both generated assembly files were inspected and compared. For this particular program, the resulting assembly was identical.
This is due to the simple nature of the program. Later as our programs become complex in nature we can clearly see the diffrence
 in the generated assembly due to optimizations.

## Assembly Observations

The generated assembly contained:

- `.text` — section containing executable instructions.
- `main` — entry-point function.
- `movl` — moves immediate values into memory.
- `leaq` — calculates an address.
- `callq printf@PLT` — calls the `printf` function through the PLT.
- `retq` — returns from the function.
- `.rodata` — stores read-only string constants.

The string `"Akshat"` was stored as a constant, while `"Hello %s\n"` was used as the `printf` format string.

Explored the individual stages of C compilation, inspected intermediate compilation artifacts, and examined the assembly generated by different optimization levels.
