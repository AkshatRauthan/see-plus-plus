## 🧭 About

`See Plus Plus` is my long-term journey into **C, C++, and Systems Programming**.

The objective is simple: understand how software works beneath the abstractions.

From pointers and memory management to operating systems, concurrency, networking, and performance engineering — this repository documents the process of learning, experimenting, and building things closer to the metal.

Not just learning the languages. Understanding the machine.

## 🔬 Areas of Exploration

| Area                 | What I'll be exploring                                            |
| -------------------- | ----------------------------------------------------------------- |
| **C Programming**    | Pointers, memory management, data structures, undefined behaviour |
| **Unix Systems**     | Processes, signals, file descriptors, syscalls, IPC               |
| **Computer Systems** | Assembly, linking, loading, virtual memory, CPU caches            |
| **Concurrency**      | Threads, synchronization, atomics, lock-free programming          |
| **Networking**       | TCP/IP, sockets, event loops, network servers                     |
| **Modern C++**       | RAII, move semantics, templates, C++20                            |
| **Performance**      | Profiling, benchmarking, allocators, data-oriented design         |

## 📐 Ground Rules

- Understand before implementing.
- Write the core of every project myself.
- Treat compiler warnings and sanitizer reports seriously.
- Read documentation and man pages, not just tutorials.
- Test and debug methodically.
- Profile before optimizing.
- Document what breaks, why it breaks, and how it gets fixed.
- Never skip a stage's major project.
